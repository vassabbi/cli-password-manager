# Password Manager CLI (Java)

Учебный проект — консольный менеджер паролей с поддержкой:
- шифрованного хранилища (AES-GCM)
- авторизации пользователя
- резервных копий (backup / restore)
- CRUD-операций над записями
- чистой архитектуры с разделением ответственности

## Основные возможности

- 🔐 **Шифрованное хранилище**
  - Vault хранится в зашифрованном виде (AES/GCM)
  - Ключ выводится из пароля пользователя через PBKDF2
- 👤 **Авторизация**
  - Успешная дешифровка vault = успешный вход
  - Нет отдельного хранения хешей паролей
- 💾 **Backup / Restore**
  - Создание резервных копий vault
  - Восстановление только после успешной проверки пароля
- 🧩 **CRUD для записей**
  - Добавление, удаление, обновление, поиск
- 🧠 **EntryMetadata**
  - Метаданные редактируемых полей вынесены отдельно
- 🏗 **Чистая архитектура**
  - Controller / Service / Repository / Model
  - Оркестрация через ApplicationService

## Авторизация

В проекте **не используется отдельное хранилище пользователей**.

### Подход:
- При входе:
  1. Загружается зашифрованный vault-файл
  2. Производится попытка дешифровки с введённым паролем
  3. Если дешифровка успешна — вход разрешён
  4. Если нет — неверный пароль или повреждённый файл

## Безопасность

- 🔑 AES-256-GCM
- 🧂 Уникальный `salt` для каждого файла
- 🔄 PBKDF2WithHmacSHA256
- 🔐 `IV` генерируется случайно для каждого шифрования
- ❌ Backup нельзя восстановить без знания пароля

## Backup и восстановление

- Backup — это копия **зашифрованного** vault
- При восстановлении:
  - сначала проверяется возможность дешифровки backup
  - только после этого файл копируется
- Это предотвращает:
  - перезапись данных при неверном пароле
  - атаки на существующий vault


## Архитектура

- Controller — работа с CLI
- Service — бизнес-логика
- Repository — работа с файловой системой
- ApplicationService — оркестрация use-case'ов
- EntryMetadata — метаданные редактируемых полей
